L66 Listing Assistant DEV

Informacje techniczne o niezależnym, prywatnym projekcie korzystającym z Allegro REST API. Nazwa powyżej odpowiada nazwie zarejestrowanej aplikacji i nie oznacza oficjalnej integracji z systemami żadnej firmy.

1. Cel aplikacji

Aplikacja jest tworzona na potrzeby własnych testów technicznych i wspomagania przygotowywania opisów produktów. Ma ułatwiać odnajdywanie produktów w Katalogu Allegro oraz sprawdzanie kategorii i wymaganych parametrów. Nie jest udostępniana innym sprzedawcom.

2. Zakres funkcjonalny

  • Wyszukiwanie produktów w katalogu na podstawie nazwy, modelu lub kodu GTIN/EAN.
  • Pobieranie identyfikatorów produktów, kategorii i dostępnych parametrów.
  • Odczyt udostępnionych przez API informacji o ograniczeniach katalogowych i markach chronionych, jeśli są dostępne w odpowiedzi.
  • Prezentacja informacji pomocniczych do ręcznego przygotowania oferty.

Aplikacja nie publikuje, nie modyfikuje ani nie usuwa ofert, nie pobiera zamówień i nie przetwarza danych kupujących.

3. Połączenie z Allegro

Planowane połączenie wykorzystuje oficjalne Allegro REST API i protokół OAuth 2.0. Do zasobów udostępnionych w trybie aplikacyjnym stosowany będzie grant client_credentials. Dostęp do zasobów wymagających autoryzacji konta sprzedawcy nie jest obecnie planowany.

4. Uprawnienia i wykorzystywane dane

W rejestracji aplikacji zaznaczono zakres allegro:api:sale:offers:read (odczyt danych ofert). Obecny etap nie zakłada odczytywania prywatnych ofert konta; zakres wybrano jako minimalne uprawnienie odczytu wymagane przez formularz rejestracyjny. Planowane zapytania dotyczą publicznie udostępnionych w API danych katalogowych, np. zasobów /sale/products, /sale/categories i parametrów kategorii. Każdy zasób będzie wykorzystywany tylko w zakresie dostępnych uprawnień.

5. Bezpieczeństwo

Dane uwierzytelniające (Client Secret, tokeny OAuth) nie są publikowane w repozytorium ani na tej stronie. Będą przechowywane w lokalnej konfiguracji poza kontrolą wersji. Aplikacja będzie stosować połączenia HTTPS, odczytowe żądania API oraz ograniczenie liczby zapytań. Nie jest połączona z żadnym firmowym kontem Allegro.

6. Status projektu

Wersja rozwojowa. Integracja jest na etapie konfiguracji i testowania. Funkcje opisane jako planowane mogą nie być jeszcze uruchomione.
